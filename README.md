**🍕 Pizza Sales Analysis — SQL Data Analytics Project**

**📌 Project Overview**

The Pizza Sales Analysis project uses SQL to analyze pizza sales data and extract meaningful business insights.
The main objective is to understand:
Overall sales performance
Customer ordering patterns
Popular pizza products and sizes
Category-wise sales distribution
Peak ordering hours
Daily demand and revenue trends
Revenue contribution of individual pizza types
The project is divided into Basic, Intermediate, and Advanced SQL business questions.

**🛠️ Tools & Technologies**

Database: MySQL
Language: SQL
Project Type: Data Analytics
Presentation: PowerPoint

**🧠 SQL Concepts Used**

The project focuses on the following SQL concepts:
`SELECT`
`WHERE`
`JOIN`
`GROUP BY`
`ORDER BY`
Aggregate functions such as `SUM()`, `COUNT()`, `AVG()`, `MAX()`
Date and time-based analysis
Window functions
Revenue percentage calculations
Cumulative revenue analysis

**📊 Main Business Metrics**

The analysis focuses on:
Total number of orders
Total pizza quantity sold
Total revenue
Average daily pizza sales
Revenue percentage by pizza type
Category-wise pizza quantity
Order distribution by hour
Popular pizza sizes and types.
